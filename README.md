# Профсоюз работников образования города Астаны

Статический сайт на HTML, CSS и JavaScript. Откройте `index.html` в браузере или разместите папку проекта на статическом веб-хостинге.

## Возможности

- Интерфейс на казахском, русском и английском языках.
- Внутренние страницы правовой базы, деятельности, обучения и вопросов-ответов.
- В разделе «Новости» размещены четыре публикации Facebook со встроенными видео и полными статьями на казахском, русском и английском языках.
- Контактный блок содержит социальные сети, ссылку на маршрут в 2ГИС и временную заглушку Telegram до появления официального канала.
- В разделах «Курсы повышения квалификации» и «Акты профсоюза» документы открываются для чтения прямо на сайте, без ссылок на скачивание или старый сайт.
- Файлы Word преобразованы в локальные HTML-страницы; PDF читаются во встроенном окне браузера.
- В меню «О профсоюзе» добавлены история и вложенное меню руководящих органов; аппарат содержит актуальную карточку бухгалтера Исатаевой Эльмиры Нукеновны.
- Запись на курс и форма вопроса подготавливают письмо на `prof_adilet@mail.ru`. Для серверной отправки и хранения заявок потребуется подключить backend.
- Контакты и ссылки на социальные сети вынесены на первый экран.
- Встроенный помощник отвечает на частые вопросы по локальной базе FAQ. Это не облачная ИИ-модель и не юридическая консультация; для подключения настоящей модели потребуется защищенный серверный API.
- GitHub Actions публикует сайт на GitHub Pages при каждом push в ветку `main`.

Нормативные ссылки ведут на официальную правовую систему «Әділет».
