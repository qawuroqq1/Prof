# Профсоюз работников образования города Астаны

Статический сайт на HTML, CSS и JavaScript. Откройте `index.html` в браузере или разместите папку проекта на статическом веб-хостинге.

## Возможности

- Интерфейс на казахском, русском и английском языках.
- Внутренние страницы правовой базы, деятельности, обучения и вопросов-ответов.
- В разделе «Новости» размещены четыре публикации Facebook со встроенными видео и полными статьями на казахском, русском и английском языках.
- Контактный блок содержит социальные сети, ссылку на маршрут в 2ГИС и ссылку на официальный Telegram-бот.
- В разделах «Курсы повышения квалификации» и «Акты профсоюза» документы открываются для чтения прямо на сайте, без ссылок на скачивание или старый сайт.
- Файлы Word преобразованы в локальные HTML-страницы; PDF читаются во встроенном окне браузера.
- В меню «О профсоюзе» добавлены история и вложенное меню руководящих органов; аппарат содержит актуальную карточку бухгалтера Исатаевой Эльмиры Нукеновны.
- Запись на курс и форма вопроса подготавливают письмо на `prof_adilet@mail.ru`. Для серверной отправки и хранения заявок потребуется подключить backend.
- Контакты и ссылки на социальные сети вынесены на первый экран.
- Чат-помощник подключается к OpenAI через Cloudflare Worker; API-ключ хранится только в секретах Worker. До настройки адреса Worker чат продолжает отвечать по локальной базе FAQ.
- GitHub Actions публикует сайт на GitHub Pages при каждом push в ветку `main`.

Нормативные ссылки ведут на официальную правовую систему «Әділет».

## Подключение ИИ-помощника

1. Создайте API-ключ в OpenAI Platform. Не добавляйте его в файлы сайта и не отправляйте в чаты или репозиторий.
2. В Cloudflare создайте Worker, вставьте содержимое `worker.js` и опубликуйте его.
3. В настройках Worker добавьте переменные:
   - `OPENAI_API_KEY` — секрет с вашим API-ключом OpenAI;
   - `OPENAI_MODEL` — `gpt-4o-mini`;
   - `ALLOWED_ORIGIN` — origin сайта, например `https://username.github.io` (без пути `/repository` и завершающего слеша).
4. Скопируйте URL опубликованного Worker и укажите его в `ASSISTANT_API_URL` в `script.js`.
5. Опубликуйте изменения сайта. Проверьте, что API-биллинг включён в OpenAI Platform; задайте доступные лимиты/уведомления расходов. Worker — публичный endpoint: проверка origin ограничивает браузерные вызовы, но не защищает от прямых автоматических запросов.

Вопросы посетителей передаются OpenAI для генерации ответов. Не отправляйте через чат персональные, медицинские или иные чувствительные сведения. Помощник не предоставляет юридических заключений.
