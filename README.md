# Профсоюз работников образования города Астаны

Статический сайт на HTML, CSS и JavaScript. Откройте `index.html` в браузере или разместите папку проекта на статическом веб-хостинге.

## Возможности

- Интерфейс на казахском, русском и английском языках.
- Внутренние страницы правовой базы, деятельности, обучения и вопросов-ответов.
- На главной показываются четыре последние публикации с доступным встроенным Facebook-видео. Полный «Архив новостей» доступен отдельным пунктом меню: публикации сгруппированы по годам и месяцам; для роликов, встраивание которых Facebook ограничил, в архиве показана ссылка на оригинал вместо заблокированного плеера. Даты публикации взяты из данных Facebook (местное время Астаны), а новые публикации переведены на казахский, русский и английский языки.
- Логотип Профсоюза используется как значок сайта (favicon).
- Региональное Соглашение на 2026–2028 годы показывается постранично на canvas без текстового слоя; просмотрщик блокирует выделение, контекстное меню и стандартные сочетания копирования. PDF.js (Apache-2.0) хранится локально в `assets/pdfjs`.
- Защита от копирования в браузере носит ограничительный характер: снимки экрана, OCR и доступ к публичным ресурсам статического сайта технически предотвратить нельзя.
- Контактный блок содержит социальные сети, ссылку на маршрут в 2ГИС и ссылку на официальный Telegram-бот.
- В разделах «Курсы повышения квалификации» и «Акты профсоюза» документы открываются для чтения прямо на сайте, без ссылок на скачивание или старый сайт.
- PDF «Положение о Первичной организации Профсоюза работников образования города Астаны» открывается во встроенном просмотрщике. История Профсоюза опубликована в виде временной шкалы; состав Совета и Исполнительного комитета выводится текстовыми карточками из предоставленных двуязычных документов.
- В меню «О Профсоюзе» размещены история, состав руководящих органов и аппарат из семи сотрудников.
- Запись на курс подготавливает письмо на `ec.profsistema@gmail.com`, а форма вопроса открывает письмо на `prof_adilet@mail.ru`. К выбранному PDF (необязательно, до 2 МБ) нужно вручную прикрепить файл в почтовой программе перед отправкой: браузер не может автоматически добавить файл в `mailto:`.
- Контакты и ссылки на социальные сети вынесены на первый экран.
- Чат-помощник подключается к OpenAI через Cloudflare Worker; API-ключ хранится только в секретах Worker. Интерфейс предлагает категории вопросов и сохраняет до восьми последних сообщений диалога. Worker передает модели только релевантные выдержки из FAQ и проверенные сведения сайта, поддерживает свободный ввод и просит модель отвечать на языке вопроса. Поиск основан на ключевых словах и многоязычных подсказках, не на embeddings; изменения `worker.js` начинают действовать после повторной публикации Worker в Cloudflare.
- GitHub Actions публикует сайт на GitHub Pages при каждом push в ветку `main`.

Нормативные ссылки ведут на официальную правовую систему «Әділет».

## Подключение ИИ-помощника

1. Создайте API-ключ в OpenAI Platform. Не добавляйте его в файлы сайта и не отправляйте в чаты или репозиторий.
2. В Cloudflare создайте Worker, вставьте содержимое `worker.js` и опубликуйте его.
3. В настройках Worker добавьте переменные:
   - `OPENAI_API_KEY` — секрет с вашим API-ключом OpenAI;
   - `OPENAI_MODEL` — `gpt-4o-mini`;
   - `ALLOWED_ORIGIN` — разрешённые origin, разделённые запятыми, например `https://username.github.io,https://example.kz` (без путей и завершающих слешей).
4. Скопируйте URL опубликованного Worker и укажите его в `ASSISTANT_API_URL` в `script.js`.
5. Опубликуйте изменения сайта. Проверьте, что API-биллинг включён в OpenAI Platform; задайте доступные лимиты/уведомления расходов. Worker — публичный endpoint: проверка origin ограничивает браузерные вызовы, но не защищает от прямых автоматических запросов.

Вопросы посетителей передаются OpenAI для генерации ответов. Не отправляйте через чат персональные, медицинские или иные чувствительные сведения. Помощник не предоставляет юридических заключений.

## Форма вопроса и PDF

Форма подготавливает письмо в почтовой программе посетителя. Если выбран файл, его имя добавляется в текст письма как напоминание, но сам файл нужно приложить вручную перед отправкой. Автоматическое вложение из браузера без серверного или почтового сервиса невозможно. Принимаются только PDF до 2 МБ.
